# Student_Management_System

A Python-based console application for managing student records using Object-Oriented Programming, file handling, and exception handling.

## 📌 Project Description

The **Student Management System** allows users to manage student records through a simple console-based menu.

The application provides functionality to:

- Add students
- Display student records
- Search for students
- Update student information
- Delete student records
- Calculate average marks
- Save and load records using a text file

The project demonstrates important Python and Object-Oriented Programming concepts such as:

- Abstraction
- Inheritance
- Encapsulation
- Getters and Setters
- Exception Handling
- File Handling

---

## ⚙️ How the Project Works

When the program starts, it loads existing student records from the `students.txt` file.

The user is provided with the following menu:


1. Add Student
2. Display Students
3. Search Student
4. Update Student
5. Delete Student
6. Calculate Average Marks
7. Save Records
8. Exit
